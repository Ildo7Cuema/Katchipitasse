# UI/UX — Katchiitassi Elavoko

## Visual direction
Warm hospitality: deep forest green + warm sand + soft cream accents. Premium, calm, photographic. Avoid purple gradients and generic AI aesthetics.

## Typography
- Display: "Fraunces" (serif, brand)
- Body: "DM Sans"

## Navigation (cliente)
Bottom tabs: Início | Restaurante | Hospedaria | Perfil
Contactos acessível a partir do Home e Perfil.

## Screens
1. Home — brand hero, CTA restaurante/hospedaria, destaques, contacto, redes
2. Restaurant list / detail / order form / my orders
3. Rooms list / detail / reservation form / my reservations
4. Auth: login, registo, recuperar password
5. Profile + history
6. Contacts
7. Admin: login, dashboard, dishes, categories, rooms, orders, reservations, customers, settings

## States
Loading skeletons, empty states, inline form errors, toast success/error.

## Motion
Subtle fade/slide on page enter; soft press feedback on primary CTAs; hero image gentle scale.
